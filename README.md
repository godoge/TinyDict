# TinyDict — Windows 桌面离线 MDX 词典

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

一款基于 MDX / MDD 格式的 **单机离线** 词典软件：

- 仅本地解析 MDX / MDD 词库，**无任何联网查词功能**，运行时不发起网络请求；
- **挂载式词库**：选择 `.mdx` 文件或词库文件夹后**即加即用**，
  无需导入等待 —— 词条数据始终保留在原始 `.mdx/.mdd` 文件中，
  查询时按需从文件读取，磁盘占用近乎为零；
- QWebEngineView 渲染词条 HTML（音标、图片、样式，支持词条内跳转、`@@@LINK` 跟随）；
- SQLite 生词本、全局快捷键唤起、屏幕划词取词、系统托盘常驻。

> 技术栈：Python + PySide6 + mdict-utils（MDX 解析，纯 Python 无 C 扩展）
> + keyboard / pywin32（全局快捷键与系统能力）。

## 1. 环境要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11 |
| Python | **3.10 – 3.12**（3.13 一般也可运行，但以 3.10–3.12 为准） |
| 磁盘 | 程序本身很小；用户数据存放于 `~/.tinydict/`，仅含 key 索引缓存与生词本，占用极小 |

## 2. 从源码运行

安装依赖（推荐使用 **uv**，能避开 pip 在 Windows 上安装 PySide6 时偶发的"回收站安全删除"失败）：

```bash
uv venv
uv pip install -r requirements.txt
uv run main.py
```

或用系统 Python：

```bash
pip install -r requirements.txt
python main.py
```

> `mdict-utils` 仅依赖 `tqdm`、`xxhash`，不强制 `readmdict`/`python-lzo`，
> 可避免 Windows 上编译 C 扩展的麻烦。

首次启动会在用户目录创建数据文件夹 `C:\Users\<用户名>\.tinydict\`：

```
~/.tinydict/
├── dictionary.db   # SQLite：词库注册信息 / 生词本与分组（不含词条正文）
├── cache/          # MDX/MDD key 索引 pickle 缓存（挂载加速）
└── config.json     # 快捷键等配置
```

## 3. 使用说明

### 3.1 添加 MDX 词库（即加即用，无需导入）

1. 点击主窗口右上角 **「词库」** 按钮，打开词库管理；
2. 点 **「添加文件…」** 选择一个或多个 `.mdx` 文件；或点 **「添加文件夹…」**
   选择词库目录，程序会递归扫描其中全部 `.mdx`；
   - 同目录下的同名 `.mdd`（以及 `xx.1.mdd`、`xx.2.mdd` …）会自动一并挂载
     （图片 / CSS / 字体等资源）；
   - **注册只读取 MDX 头部，秒级完成**；随后后台加载 key 索引，
     列表「状态」列显示「加载中 → 就绪」，加载完成即可查询；
   - 第二次启动会直接加载本地 key 缓存，几乎无等待；
3. 列表顺序即**查询优先级**：排在前面的词库优先展示结果，用「上移 / 下移」调整；
4. 取消勾选「启用」可临时禁用某词库；**「移除词库」仅取消注册**，
   不影响原始 `.mdx/.mdd` 文件，可随时重新添加。

#### 词库文件缺失 / 路径失效怎么办

若词库所在的**文件夹被改名或移动**，原注册路径会失效。程序会自动识别
（不再卡在"加载中"），并以以下方式提示你：

- **主窗口状态栏**：出现 `⚠ N 部词库文件缺失或无法加载，点击「词库管理」查看并修复`，
  点击该文字可直接打开词库管理；
- **词库管理对话框**：对应词库状态列显示红色「文件缺失」，鼠标悬停可看到失效的
  原路径与原因，顶部还有一条红色告警列出所有缺失词库；
- **「修复路径…」按钮**（或**双击**缺失行）：为选中的词库重新指定新的 `.mdx`
  文件位置，保存后立即后台重新加载，无需重启。

> 修复只更新 TinyDict 记录的路径，**不动原始 `.mdx` 文件**。

> 与旧版"导入式"不同：词条正文与资源**不再展开进本地数据库**，
> 查询时直接从原文件按需读取单条 record（MDX 自带索引，二分定位 + 单块解压，
> 毫秒级）。因此首次添加几乎瞬时，磁盘占用近乎为零。

### 3.2 查词

- 左侧上方的搜索框输入单词，**回车**精确查词；输入过程中紧贴其下的候选列表
  实时给出前缀联想，单击联想词直接查询；
- 候选列表**始终保留当前输入的词**：词库没有收录时，它会以斜体排在首位。
  点它或直接回车都会生成「当前词条」，所以即使没有词库命中，也可以用词条
  标题右侧的 **★** 收藏到生词本，之后在生词本里双击还能查回；
- 词条区有一条**固定单词标题条**：不论词库是否收录、不论切到哪部词库，
  左边都显示当前词形；词形右侧紧跟一个圆角**工具胶囊**，里面是
  **★ 收藏 | 分隔线 | ● + 「显示笔记」** 勾选框。长词会省略显示，窗口很窄时
  先压缩词形，胶囊不会被挤走；
  当前词条写过笔记时，勾选框左侧会出现一个小圆点（面板收起时也在）；
  圆点只表示「有笔记」，面板是否展开由勾选框是否勾选决定；
- 多部词库同时命中时，词典切换标签显示在固定标题条上方；
- 词条内的 `entry://` 交叉引用链接可直接点击跳转；
- `@@@LINK=xxx` 跳转词条自动跟随（多级，防循环）；
- `←` `→` 按钮在历史记录中前进后退；**「置顶」**让窗口常驻最前。

### 3.3 生词本与分组

生词本支持**分组**（标签式多归属：一个生词可以同时属于多个分组）。

- 点固定词条标题右侧的 **★** 打开分组菜单：勾选哪些分组，当前词条就加入哪些分组；取消勾选
  即移出该分组。菜单在勾选后**不会自动关闭**，可以一次把词条加进多个分组；
  菜单最后一项 **「＋ 新建分组…」** 可随手建组；
- **★** 实心金色表示当前词条已在**任一分组**里，空心中性灰表示尚未收藏
  （未收藏用黑白灰、跟随浅/深主题，不与金色抢视觉）；鼠标悬停可看到
  它所属的所有分组。在菜单里取消**最后一个**分组等同于取消收藏，该词会从
  生词本中移除，不会被自动塞回「默认分组」；
- 点 **「生词本」** 打开生词本窗口：
  - 左侧分组栏：**全部 / 各分组**，可新建、重命名、删除、上移下移；
  - 右侧词表：双击查词，支持 Ctrl / Shift 多选；顶部输入框可**即时搜索**生词
    （不区分大小写，按字面匹配），范围就是左侧当前选中的分组，想搜整个生词本
    先切到「全部」；在搜索框按回车直接查第一条匹配结果；
  - 选中若干词后 **「加入到分组 ▸」** 可批量加组（保留原有分组归属），
    **「从本分组移除」** 只解除本分组关联、**「彻底删除」** 从生词本移除；
  - **删除分组**时可选「仅删除分组」（生词保留，只属于该组的词自动归入「默认分组」）
    或「同时删除生词」（这些词从生词本彻底移除，含其它分组中的记录）；
  - **默认分组**（随程序创建）可重命名、不可删除，作为生词本窗口批量操作的
    兜底分组：在窗口里把词移出最后一个分组、删除分组或清空分组时，它会自动
    归入此处，不会变成无归属（★ 菜单里的「取消勾选」不走这条兜底，见上文）。

> 旧版本（无分组功能）已有的生词，升级后会**自动归入「默认分组」**，
> 不会丢失。

### 3.4 词条笔记与跨设备同步

笔记挂在**当前词条**上，词库没收录的词也能写（见 3.2 的占位词条）。
词条页下方的笔记面板由固定标题条上的 **「显示笔记」勾选框** 折叠/展开，
输入后自动保存，切换词条、隐藏面板或退出程序时都会先落盘。勾选状态
只管面板显隐；当前词条有笔记时勾选框左侧另有一个**小圆点**，与面板开合无关，
笔记收起时也能一眼看出该词写过笔记。**刚启动还没查词时显示的是欢迎页，
底部不会出现空的笔记面板**，进入第一个词条后才按上次勾选的状态展开。

**存储**：笔记与同步元数据都在 `~/.tinydict/dictionary.db` 的 `notes` 表里，
走 WAL + 事务，单条编辑是原子的。词键做了 NFKC + 大小写折叠 + 空白折叠，
`Apple` / `apple` / 全角写法不会分裂成三条。删除只写墓碑（`deleted=1`）
而不物理删行——否则一端删掉的笔记，在另一端导入旧备份时会被当成「新增」复活。

> 为什么不把笔记写成 MDX 词库：`mdict-utils` 的 `MDictWriter` 只有一次性
> 写整本的接口，没有增量更新；每次保存都整本重写，中断即损坏全部笔记，
> 笔记还会和词库文件混在一起被换库/重装覆盖。MDX 只用作导出快照。

**导出**：笔记面板右上角 **「导入 / 导出」** 提供五种格式。

| 格式 | 用途 |
|---|---|
| JSON 完整备份 | `type = "tinydict-notes"`，带 `device_id` / `updated_at` / `revision` / `deleted`，用于双向同步 |
| 手机版生词本备份 JSON | 复用 `tinydict-wordbook` v1 格式，追加可选 `note*` 字段 |
| CSV / 手机版 CSV | 表格交换；正文里的换行由 CSV 引号正确还原 |
| MDX 词库快照 | 只读，任何 MDX 词典软件都能查，不参与同步与编辑 |

`version` 一律保持 `1`：手机版旧构建遇到更高版本会直接拒绝，新增字段全部是
可选的，旧软件读到会原样忽略，不会破坏现有生词本互通。

**冲突处理（三路合并）**：每次成功导出或干净合并后，把当时双方一致的内容记为
同步基线（`note_sync`）。下次导入时比较 `base` / `local` / `remote`：

| 情况 | 结果 |
|---|---|
| `local == remote` | 不变 |
| `local == base` | 只有对端改过 → 采用导入版本 |
| `remote == base` | 只有本机改过 → 保留本机版本 |
| 其它 | 两端都改过 → 保留本机，把对端完整内容存进 `note_conflicts` |

真冲突时**不推进基线**，所以同一份文件重复导入不会把刚决定保留的内容悄悄
覆盖掉；重复留痕也会去重。面板右上角出现 **「N 条冲突待合并」**，点开可逐条
选择「保留本机 / 采用导入 / 保存合并结果」。导入对话框另提供两种策略：
**只补本地没有的**（已有笔记一律不动）与 **以导入文件为准**（无条件覆盖）。

**与手机版互通**：手机端原本只有 `words.note` 字段，没有写入路径，生词本备份
也不带笔记。需要合入本次交付的 Android 补丁（扩展 `WordbookBackup` 的导入导出、
补上笔记编辑入口与 Room 迁移）。未合入时，电脑导出的手机版格式仍能正常导入
生词，只是笔记字段会被忽略。

### 3.5 快捷键 / 划词 / 托盘（默认配置，可在「设置」中修改）

| 功能 | 默认快捷键 |
|---|---|
| 显示 / 隐藏主窗口（全局） | `Ctrl + Alt + D` |
| 屏幕划词取词（全局） | `Ctrl + Alt + Q` |

- **划词取词**：在其他应用（Word、浏览器、PDF 阅读器等）中选中文字后按取词快捷键，
  程序会模拟一次 `Ctrl+C` 读取选中文本并弹出查询（随后自动恢复剪贴板内容）。
  需要目标程序支持「Ctrl+C 复制选中内容」；
- 点击窗口关闭按钮默认**最小化到系统托盘**（托盘右键菜单可退出，或在设置中改为直接退出）；
- 托盘图标单击/双击同样可以显示/隐藏主窗口。

## 4. 手动打包指引（PyInstaller）

本仓库**不包含**任何打包脚本与安装器工程，以下步骤请自行执行。

### 4.1 安装 PyInstaller

```bash
pip install pyinstaller
```

### 4.2 打包命令（推荐 --onedir 文件夹方式）

在项目根目录执行：

```bash
pyinstaller --noconfirm --clean --onedir --windowed --name TinyDict main.py
```

- `--onedir`：输出为 `dist\TinyDict\` 文件夹（启动快、误报率相对低），
  整个文件夹拷到目标机器即可运行；
- `--windowed`（等价 `-w`）：不显示控制台窗口；
- 如需单文件 exe，把 `--onedir` 换成 `--onefile`（启动较慢且更容易被杀软误报，不推荐）。

### 4.3 体积与注意事项

- **QWebEngineView 附带 Chromium 内核**，打包产物中会包含 `Qt6WebEngineCore.dll`、
  `resources\`、`translations\qtwebengine_*.qm` 等约 **150–300 MB** 的文件，
  最终目录体积较大属正常现象，请勿手工删除这些文件；
- 若运行打包版时报缺少 `QtWebEngineProcess.exe` 等组件，可追加参数让 PyInstaller
  完整收集 PySide6 二进制：
  `pyinstaller ... --collect-binaries PySide6 --collect-submodules PySide6`
- **杀毒软件误报**：PyInstaller 打包的 exe（尤其 `--onefile` 单文件模式）被杀软误报
  是常见现象。如遇拦截，请把 `dist\TinyDict\` 目录加入杀软白名单；本软件不联网、
  无恶意行为，可放心使用；
- 全局快捷键 / 划词功能使用 `keyboard` 库的低级键盘钩子，个别安全软件可能提示
  「键盘记录器」类风险，属该库的固有工作方式，请自行判断是否放行。
- **Windows 安全中心 / SmartScreen 拦截（正常现象）**：从 GitHub Releases
  下载的压缩包用浏览器解压后，其中的 `TinyDict.exe` 及 `_internal\*.dll`
  （如 `libffi-8.dll`）会被 Windows 标记为"来自其他计算机"，首次运行时
  **Windows 安全中心可能弹出"Windows 已保护你的电脑 / 无法确认谁提供了此程序"**。
  这是**未签名开源程序的普遍现象**，并非本软件含病毒：
  - 点击弹窗中的 **「详细信息」→「仍要运行」** 即可正常启动；
  - 或在解压后的 `TinyDict` 文件夹上右键「属性」→ 底部「安全」处勾选
    **「解除锁定」→ 确定**，之后不再提示。
  - 根本消除：对发布包做代码签名，或使用 scoop / winget 等包管理器安装
    （它们会自动去掉该标记）。本软件为纯本地离线程序，无联网行为，可放心放行。

### 4.4 制作桌面安装程序（可选）

PyInstaller 只输出可执行目录。如需做成带开始菜单 / 桌面图标的安装程序
（`.msi` / `.exe` 安装包），可自行使用 **Inno Setup** 等工具把 `dist\TinyDict\`
封装，本仓库不提供相关工程。

## 5. 已知限制

- 不支持加密（需要注册码/序列号）的 MDX 词库，挂载时会提示失败；
- 词条内的音频播放（`sound://` 资源）暂未支持，音标/图片/样式渲染正常；
- 划词取词依赖「Ctrl+C 复制」机制，个别禁止复制的应用中无效；
- 部分词库 CSS 中引用的外部字体若未包含在 MDD 中，可能显示为系统默认字体；
- 超大词库（数百万词条）首次挂载需读取全部 key 建索引（几秒至几十秒），
  之后由本地缓存加速，二次启动秒级。

## 6. 项目结构

```
TinyDict/
├── main.py                        # 启动入口（注册 mdx:// scheme 并创建应用）
├── requirements.txt
├── README.md
└── tinydict/
    ├── paths.py                   # 数据目录约定（~/.tinydict/）
    ├── config.py                  # JSON 配置
    ├── app.py                     # 组装层：托盘 / 热键 / 划词接线
    ├── core/
    │   ├── database.py            # SQLite：词库注册信息 / 生词本
    │   ├── mdx_access.py          # 挂载式 MDX/MDD 访问器（key 缓存 + 按需读单块）
    │   ├── query.py               # 词典服务：注册 / 后台挂载 / 查词 / 建议 / 资源
    │   └── wordbook.py            # 生词本与分组（标签式多归属）
    ├── ui/
    │   ├── main_window.py         # 主窗口（搜索 / 渲染 / 历史 / 星标分组 / 挂载状态）
    │   ├── scheme_handler.py      # mdx:// 资源请求处理器（从 MDD 原文件按需读）
    │   ├── dict_manager_dialog.py # 词库管理对话框（添加文件 / 文件夹）
    │   ├── wordbook_dialog.py     # 生词本窗口（左侧分组栏 + 右侧词表）
    │   ├── settings_dialog.py     # 设置对话框（含语言切换）
    │   └── icons.py               # 程序图标（代码绘制）
    └── system/
        ├── hotkeys.py             # 全局快捷键（keyboard 库）
        └── capture.py             # 屏幕划词取词
```
